# Сервис распределения расходов поездки

## Назначение

Приложение помогает группе людей, путешествующих вместе, учитывать общие
расходы поездки и честно делить их между участниками. Сервис считает долю
каждого, показывает, кто сколько переплатил или недоплатил, и формирует
итоговый расчет: кто, кому и сколько должен перевести. Это избавляет от
ручных подсчетов в заметках и споров после поездки.

## Целевая аудитория

- друзья и семьи, которые вместе отправляются в отпуск или поход;
- студенческие группы на выездных мероприятиях;
- коллеги в командировках с общими тратами;
- организаторы групповых туров, которым нужно вести общий бюджет.

## Предметная область

Совместные поездки и учет общих трат. Группа создает поездку с датами и
бюджетом, добавляет участников и по ходу поездки вносит расходы: жилье,
транспорт, еду, билеты. Каждый расход оплачивает один из участников, а
делится он между всеми или частью группы. По итогам сервис рассчитывает
балансы участников и минимальный набор переводов для взаиморасчета.

## Основные сущности

- **Поездка** — название, даты начала и окончания, бюджет, валюта.
- **Участник** — имя, контакт, принадлежность к поездке.
- **Расход** — название, сумма, дата, категория, кто оплатил, между кем делится.
- **Расчет** — доля и баланс каждого участника, список переводов «кто → кому → сколько».

## Основные функции

- создание поездки и расчет ее длительности по датам;
- добавление участников поездки;
- добавление расхода с проверкой корректности введенной суммы;
- расчет доли каждого участника в общем расходе;
- расчет баланса участника (переплатил / должен доплатить);
- формирование итогового расчета между участниками;
- контроль бюджета поездки (предупреждение при приближении к лимиту и при превышении).

## Реализовано на ПР1

Начальный сценарий в `main.py`: поездка с тремя участниками, один из них
оплачивает общий расход. Программа:

1. считает длительность поездки (`get_trip_duration`, модуль `datetime`);
2. преобразует строку с суммой в число и проверяет ее (`parse_amount`);
3. проверяет расход относительно бюджета (`check_budget`);
4. рассчитывает долю каждого участника (`calculate_share`, модуль `math`);
5. считает баланс участников (`calculate_balance`);
6. выводит итоговый расчет для каждого (`get_settlement_status`).

## Запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Тесты:

```bash
pytest
```

Пример вывода:

```
Поездка: Поездка в Казань
Даты: 03.11.2026 – 06.11.2026 (4 дн.)
Участники: Ираклий, Анна, Максим

Расход: Аренда квартиры — 25500.00 ₽, оплатил Ираклий
Внимание: израсходовано 85% бюджета

Доля каждого участника: 8500.00 ₽
Ираклий: ему должны вернуть 17000.00 ₽
Анна: должен перевести 8500.00 ₽
Максим: должен перевести 8500.00 ₽
```

## План развития

На следующих этапах планируется:

- ПР2: консольная программа с несколькими поездками, списками участников и расходов, модули и обработка исключений;
- ПР3: сущности «Поездка», «Участник», «Расход», «Расчет» в виде классов;
- разработка веб-приложения на Django;
- подключение базы данных и моделей предметной области;
- реализация пользователей, регистрации и разграничения доступа к поездкам;
- разработка REST API;
- контейнеризация приложения в Docker;
- настройка CI/CD и автоматических тестов.
